# 时璃 Timeglass

一款 Windows 桌面小工具，核心是两件事：**自动记录你的屏幕**（定时截屏 + 归档），以及**给窗口套一层会自动配色的玻璃外壳**。附带一个图形化 FFmpeg 转码工坊。

> 名字「时璃」：**时**间（定时记录）+ 玻**璃**（毛玻璃外壳）。

## 它能做什么

### 1. 定时截屏 —— 自动记录你在看什么

- 每隔一段时间自动截一张屏（间隔 **1 分钟到 24 小时随便填**，不是只有几档可选）
- 可以只在**特定时段**采集（比如 09:00~18:00），也可以选**全天**
- 截出来的图**画面是干净的**——时间、你当时用的应用名、窗口标题，都写在旁边的一份元数据里，不糊在图上
- 按**日历**管理，每天截了几张一目了然；归档页能按应用名 / 标题搜索
- 多屏时，**截你鼠标所在的那块屏**（不是永远只截主屏）
- 一堆防打扰 / 省空间的细节：
  - 画面**去重**（连续两张一模一样就跳过）
  - **锁屏暂停**、**全屏应用暂停**（比如打游戏 / 看视频时不截）
  - **排除名单**（指定某几个应用在前台时跳过）
  - **空闲自动暂停**：键鼠多久没动就暂停（时长自己设）
  - 存储上限（超了自动删最旧的）
- 常驻托盘：右键菜单、左键浮出面板（今日统计 / 一键暂停 / 立即截屏）
- 开机自启、关窗口最小化到托盘、全局热键暂停

### 2. 转码工坊 —— 图形化 FFmpeg

拖文件进去就能转码，还能**实时预览命令行**（所见即所执行）：

- 容器（mp4 / mkv / webm）、编码器（H.264 / H.265 / 直通）、NVENC 硬件加速开关
- 码率 / CRF 恒定质量、分辨率（保持 / 指定 / 缩放%）、帧率（保持 / 常见档 / **自定义任意值**）
- **时间段截取**：填开始秒 ~ 结束秒（支持小数），只转想留的那一段
- **自定义输出文件名**：留空自动命名，填了就用你的（自动补扩展名、过滤非法字符）
- 选文件后显示**源文件大小 · 时长 · 预估输出大小**（按时长折算）
- 转码队列实时进度 / 倍速 / 输出大小，完成自动清理

### 3. 玻璃主题 —— 自动配色，跟着壁纸变

- 导入任意图片当壁纸，引擎自动从图里**取主题色**，生成整套配色
- 有两种**采样方式**（整体色调 / 主色簇），下面是几个**候选色**，点哪个就用哪个当主题色
- 每块面板会按「它背后那块壁纸」单独算玻璃色，颜色是活的
- 会自动抬升对比度，保证文字看得清（符合无障碍对比度标准）
- 材质可调：不透明度、模糊、圆角、阴影，五处材质槽还能微调

### 4. 键鼠活跃度 —— 记下你什么时候在忙

后台用系统级全局钩子（uiohook）记录键鼠操作，按分钟聚合，不碰截图：

- **键盘按键次数**（长按只算一次，不会被系统键盘重复虚增）
- **鼠标点击次数**
- **鼠标移动像素**

时间轴上以**日历热力**呈现：每天一格，颜色深浅 = 当天活跃度；点某天看**当天 24 小时热力条**，可**单击 / Shift 连选 / Ctrl 多选**小时格，查看区间累加（键盘 / 点击 / 移动），数字**实时跳动**，含当前小时的区间会标注「进行中」。

## 快速开始

```bash
# 1. 装依赖（建议国内镜像）
npm install --registry=https://registry.npmmirror.com

# 2. 跑起来
npm start        # 或双击 start.bat
```

## 依赖

- **Node.js ≥ 18** + npm
- **FFmpeg**（只有「转码工坊」需要）：装 [gyan.dev](https://www.gyan.dev/ffmpeg/builds/) 的 full build，把 `bin` 加进 PATH。命令行跑 `ffmpeg -version` 有输出即可。
- 截屏、托盘、自启、取色**都不需要**额外依赖（Electron 内置 + Windows API）。

## 数据存哪了

| 内容 | 位置 |
|---|---|
| 截图 | `图片\Timeglass\YYYY-MM-DD\TG_HHMMSS.png` |
| 设置 + 元数据 | `%APPDATA%\timeglass\data\`（settings.json / meta.json） |
| 键鼠活跃度 | `%APPDATA%\timeglass\data\activity\YYYY-MM-DD.json`（按分钟 k/c/m） |
| 主题状态 | 渲染进程 localStorage |

## 目录结构

```
timeglass/
├─ main.js            主进程：窗口 / 托盘 / 调度 / 自启 / 热键 / IPC
├─ preload.js         contextBridge 安全桥
├─ tray.html          托盘浮出面板
├─ lib/
│  ├─ store.js        设置 + 元数据持久化
│  ├─ capture.js      截屏 + 窗口信息 + 去重 + 保留策略
│  ├─ activity.js     键鼠活跃度采集（uiohook 全局钩子，按分钟聚合）
│  ├─ activityStore.js 活跃度按天持久化
│  └─ transcode.js    FFmpeg 参数 + 队列 + 进度
├─ renderer/
│  ├─ index.html      外壳（标题栏 + 侧栏 + 五个视图）
│  ├─ app.css         样式（全部吃引擎令牌）
│  ├─ app.js          视图渲染与交互
│  ├─ engine.js       玻璃取色引擎
│  ├─ tray.js         托盘面板逻辑
│  └─ mcu.iife.js     material-color-utilities
├─ assets/            托盘图标等资源
├─ build/             应用图标源文件 + 生成脚本产物
└─ tools/             图标生成脚本
```
